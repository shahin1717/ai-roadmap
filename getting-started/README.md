# Getting Started

Everything you need before the math starts: a place to run code, just enough Python and NumPy to follow the notebooks, and a quick tour of how this repo is organised. No prior programming is assumed.

> **Status:** Python basics is written. Setup and How to use this repo are still planned. Until Setup is ready, the quickest way in is **Open in Colab**: every notebook has a button at the top that runs it in your browser with nothing to install.

## Prerequisites

High-school math and curiosity. That's it.

## Study order

1. [Setup](setup/README.md): get Python, VS Code, and Jupyter running on your computer, or skip installing and use Colab. *(planned)*
2. [Python Basics](python-basics/README.md): variables, collections, loops, functions, NumPy arrays, and plotting, just enough for the math notebooks. Includes a notebook, 11 exercises with solutions, and an assignment.
3. [How to Use this Repo](how-to-use-this-repo/README.md): how each topic is laid out and how to study it. *(planned)*

When you finish, continue to [Math: Linear Algebra](../math/linear-algebra/vectors-and-matrices/README.md).
