# Getting Started

Everything you need before the math starts: a quick tour of how this repo is organised, a place to run code, and just enough Python and NumPy to follow the notebooks. No prior programming is assumed.

> **Status:** Setup and Python basics are written. How to use this repo is still planned. If you would rather not install anything, **Open in Colab** runs any notebook in your browser: every notebook has the button at the top.

## Prerequisites

High-school math and curiosity. That's it.

## Study order

1. [How to Use this Repo](how-to-use-this-repo/README.md): how each topic is laid out and how to study it. *(planned)*
2. [Setup](setup/README.md): how Python and pip work, then set up your own environment with Miniconda or venv, plus VS Code and Jupyter, or skip installing and use Colab. Includes a check-your-setup notebook, nine exercises, and an assignment.
3. [Python Basics](python-basics/README.md): variables, collections, loops, functions, NumPy arrays, and plotting, just enough for the math notebooks. Includes a notebook, 11 exercises with solutions, and an assignment.

When you finish, continue to [Math: Linear Algebra](../math/linear-algebra/vectors-and-matrices/README.md).
